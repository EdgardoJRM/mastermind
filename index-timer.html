🚀 Cómo Usar

  • Paso 1: Abre timer.html en dos ventanas/pestañas
  • Paso 2: En una selecciona "Panel de Control", en otra "Pantalla de Proyección"
  • Paso 3: Selecciona una sesión y haz clic en "Iniciar"
  • Paso 4: Verás el temporizador en la pantalla de proyección
  • Paso 5: Usa los controles para pausar, reanudar o ir a la siguiente sesión

✨ Características

  • ✅ Sincronización en tiempo real entre dos vistas
  • ✅ Indicadores visuales (verde, amarillo, rojo)
  • ✅ Información completa del evento
  • ✅ Ajuste manual de tiempos
  • ✅ Persistencia de estado
  • ✅ Diseño responsivo
  • ✅ Fácil de personalizar

🔧 Personalización

  • Editar Agenda: Abre agenda.js y modifica el array AGENDA
  • Cambiar Colores: Edita timer-styles.css y modifica las variables CSS
  • Agregar Sesiones: Añade nuevos objetos al array AGENDA
  • Cambiar Presentadores: Actualiza el campo "presentador" en cada sesión

🌐 Despliegue en Vercel

  • Paso 1: Crea un repositorio Git: git init && git add . && git commit -m "Initial commit"
  • Paso 2: Sube a GitHub
  • Paso 3: Conecta en vercel.com
  • Paso 4: Vercel desplegará automáticamente
  • Resultado: Tu URL será: https://tu-proyecto.vercel.app/timer.html
